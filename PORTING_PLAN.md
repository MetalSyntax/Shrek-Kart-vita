# Shrek Kart (iOS) → PS Vita

> Port plan (psvita-toolkit `init --ipa`, 2026-11-04). Source: iOS IPA, 32-bit Mach-O, loaded on the Vita by
> our own Mach-O loader + Objective-C runtime (shared by the 6 iOS ports; master copy in
> `Ferrari-GT-Evolution-vita/source`, synced with `tools/sync_runtime.sh`).
>
> **For AI agents:** source of truth for this port. Tick `[x]` for console items only with evidence
> (log line, dump, commit). Never record an engine fact without symbol/disassembly evidence. Keep in English.
> This is NOT an Android port: no `.so`, no JNI. One console bug per run, guided by `logs/shrekkart_NNN.log`.

## 1. Architecture (what replaced the broken ios-loader-boilerplate)

`psvita-toolkit init --ipa` copies `ios-loader-boilerplate`, which does not build (missing fields,
non-fixed mapping, broken `annotate.py`) and has no ObjC runtime. This port uses instead:

| File | Role |
|---|---|
| `tools/ios_prep.py` | Host-side Mach-O analysis → `rebase.bin` + `binds.bin`. PIE: exact (dyld_info opcodes). Classic non-PIE without relocs (iPhone OS 2/3, `-mdynamic-no-pic`): exact ObjC/cfstring/stubs walk + **recursive-descent ARM disassembly** (capstone) to classify literal-pool words, jump tables (`ldrls pc,[pc,rX,lsl#2]`), PIC literals (`add rX,pc,rX`), vtables. Validated against HAWX symbols: 0 missed pointers, 0 data false positives. |
| `source/macho.c` | Maps every segment at `vmaddr + 0x98000000` (kubridge fixed blocks), applies the two tables, thunks unresolved imports to a logging stub. |
| `source/asm.S` | `call_guest*` (r9 preserved), `ml_align_call` (4→8 stack alignment), `objc_msgSend[_stret]`, `objc_msgSendSuper2[_stret]`, `objc_call_imp[6]`, Darwin `setjmp/longjmp`. |
| `source/objc.c` | ObjC 2 runtime: registers the game classes from `__objc_classlist`, interns selectors, method cache, categories, "native" classes (`objc_define`) that game classes can subclass, refcount header + autorelease pools, auto-generated empty classes for unimplemented frameworks. |
| `source/foundation.c` | NSObject/NSString(=CFString layout)/NSNumber/NSArray/NSSet/NSDictionary/NSData, binary plist, NSBundle, NSUserDefaults (persisted, `AppleLanguages` = Vita language), NSFileManager, NSTimer/NSRunLoop/CFRunLoop, NSThread, NSLock, NSNotificationCenter, NSLocale, CF*. |
| `source/uikit.c` | UIApplicationMain (+ precompiled MainWindow nib), UIView/UIWindow/CALayer/CAEAGLLayer/EAGLContext, UIScreen/UIDevice, UIAccelerometer (left stick), UITouch/UIEvent, UIImage + CoreGraphics bitmap contexts (PNG/CgBI decode, CTM), UITextField → IME, UIAlertView (auto-dismiss), MPMoviePlayer (skipped), GLKView/GLKViewController, CADisplayLink, run loop. |
| `source/gles.c` | GLES1 → vitaGL: drawable FBO (+depth) presented rotated/scaled to 960x544, OES FBO emulation, GL_FIXED conversion (incl. VBOs), **GL_OES_matrix_palette emulated on CPU**, iPhone-like `glGetString`. |
| `source/openal.c`, `audio.c` | openal-soft (+ `alBufferDataStatic`); AudioSession stubs; AudioFile over `.ogg`/`.wav`; AudioQueue PCM → `sceAudioOut` thread (48 kHz resample). |
| `source/ios5.c` | Blocks, GCD (main queue + workers + dispatch_after/once/semaphores), ARC entry points, OSAtomic, sqlite (SceSqlite), ExtAudioFile, Mach/Keychain/SSL stubs. |
| `source/darwin.c` | Darwin libc/pthread/compiler-rt on newlib with converted structs (`stat`, `dirent`, `tm`, `pthread_attr/cond/once`), `_DefaultRuneLocale` ctype, Darwin printf (`%@`), offline sockets. |
| `source/cxx_imports.c` | Generated by `tools/gen_cxx.py`: iOS libstdc++ (COW ABI) imports → VitaSDK libstdc++ old-ABI symbols (`size_t` m→j). |
| `source/port_config.h`, `patch.c` | The only per-game files. |

## 3. Crash triage (iOS specifics)

1. `python3 -I tools/deploy_data.py --logs` → newest `logs/shrekkart_NNN.log` (+ `.psp2dmp`).
2. PC ≥ 0x98000000 → game code at PC − 0x98000000 (`otool -tV game_app/ShrekKarting`; HAWX has symbols).
3. Data abort at an address < 0x02000000 → a pointer was **not** rebased. Find the literal/data word in `ux0_data/shrekkart/report.txt` (`DUDA` lines list every rejected candidate with its address) and add the classification rule (or a one-off fix) in `tools/ios_prep.py`; re-run `tools/stage_data.sh` and redeploy only `rebase.bin`.
4. Garbage value ≈ 0x98xxxxxx where a number was expected → false-positive rebase (rare after validation).
5. `objc: -[X sel] sin implementar` → add the selector to the native class (uikit.c/foundation.c, master copy in Ferrari) and `tools/sync_runtime.sh` to the other ports.
6. `unimpl: _foo` → add to the right table (`darwin.c`, `ios5.c`, ...).
